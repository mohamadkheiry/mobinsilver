# راهنمای فنی و محتوایی مجله مبین

مجله مبین یک زیرسامانه محتوایی متصل به دیتابیس است؛ مقاله‌ها صفحه ثابت نیستند و از طریق API عمومی و پنل ادمین مدیریت می‌شوند.

## قابلیت‌ها

- صفحه فهرست مجله در `/blog` با مقاله ویژه، جستجو و فیلتر دسته‌بندی
- صفحه مستقل و قابل اشتراک هر مقاله در `/blog/{slug}`
- فهرست مطالب خودکار بر اساس عنوان‌های متن و مقاله‌های مرتبط بر اساس دسته‌بندی
- پیش‌نویس، انتشار فوری یا زمان‌بندی‌شده و مقاله ویژه
- ایجاد، ویرایش، پیش‌نمایش و حذف با دسترسی Admin
- رندر امن متن بدون اجرای HTML ذخیره‌شده در دیتابیس
- تصاویر اختصاصی در `public/assets/blog-*.png`

## مدل داده BlogPost

| فیلد | کاربرد |
|---|---|
| `Title` | عنوان نمایشی مقاله |
| `Slug` | شناسه یکتای انگلیسی URL |
| `Excerpt` | خلاصه کارت و ابتدای مقاله |
| `Content` | متن ساختاریافته ساده |
| `CoverImageUrl` | مسیر تصویر شاخص |
| `Category` | دسته تحریریه |
| `Author` | نام نویسنده/تحریریه |
| `Tags` | برچسب‌های جداشده با ویرگول |
| `ReadingMinutes` | زمان مطالعه تخمینی |
| `Featured` | انتخاب برای جایگاه ویژه |
| `IsPublished` | پیش‌نویس یا منتشرشده |
| `PublishedAt` | زمان شروع نمایش عمومی به UTC |
| `CreatedAt`, `UpdatedAt` | رد زمانی ایجاد و ویرایش |

`Slug` یکتا است و فقط حروف انگلیسی، عدد و خط تیره را می‌پذیرد. مقاله عمومی باید هم `IsPublished=true` داشته باشد و هم `PublishedAt` آن گذشته یا زمان جاری باشد.

## قالب متن مقاله

ویرایشگر از یک قالب ساده، خوانا و امن استفاده می‌کند:

```text
## عنوان بخش

متن پاراگراف مقاله...

> نکته یا هشدار مهم
```

- خطی با `## ` به عنوان سطح دوم و ورودی فهرست مطالب تبدیل می‌شود.
- خطی با `> ` به نقل‌قول برجسته تبدیل می‌شود.
- سایر خط‌های غیرخالی پاراگراف هستند.
- HTML خام تفسیر نمی‌شود؛ بنابراین payload ذخیره‌شده نمی‌تواند script اجرا کند.

## گردش کار تحریریه

1. مدیر وارد `/admin` و بخش «مقالات» می‌شود.
2. «مقاله جدید» را انتخاب و عنوان، نامک، خلاصه و متن را وارد می‌کند.
3. دسته، تصویر، نویسنده، برچسب و زمان مطالعه تعیین می‌شوند.
4. برای بازبینی داخلی، مقاله با انتشار غیرفعال به‌صورت پیش‌نویس ذخیره می‌شود.
5. پس از بازبینی، انتشار فعال و زمان انتشار تنظیم می‌شود.
6. نتیجه از لینک مشاهده جدول یا مسیر عمومی کنترل می‌شود.

## دسته‌بندی‌های استاندارد

- راهنمای خرید
- دانش نقره
- سرمایه‌گذاری
- نگهداری و مراقبت

نام دسته‌ها را بدون تصمیم تحریریه تغییر ندهید؛ فیلتر frontend از همین مقادیر استفاده می‌کند.

## توسعه آینده

- ویرایشگر Rich Text با allowlist و sanitization سمت سرور
- SEO metadata، canonical URL و داده ساختاریافته Article
- تاریخچه نسخه، بازیابی حذف و گردش تأیید چندنفره
- بارگذاری امن تصویر به object storage و پردازش WebP/AVIF
- pagination و کش خروجی عمومی
- آمار مشاهده بدون ثبت داده شخصی غیرضروری
